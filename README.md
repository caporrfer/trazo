# Trazo

Landing de captación para Trazo, un estudio especializado en diseñar y poner en marcha webs para negocios locales.

## Desarrollo

```bash
npm install
npm run dev
```

La compilación de producción se genera con:

```bash
npm run build
```

## Estructura

- `/`: landing principal.
- `/empezar`: pantalla provisional del futuro formulario.
- `/empezar?plan=alojamiento`, `/empezar?plan=actualizaciones` y `/empezar?plan=desarrollo`: conservan la opción elegida.
- `lib/site.ts`: fuente única para precios, prestaciones y enlaces del formulario futuro.

## Recursos visuales

Las fotografías de los proyectos Lumbre y Cobalto/26 fueron generadas específicamente para esta web mediante OpenAI ImageGen. Ambos trabajos se presentan como proyectos conceptuales y no representan clientes reales.
