# Trazo

Landing page de Trazo, un estudio de diseño, desarrollo y mantenimiento web para negocios locales.

## Desarrollo local

Requiere Node.js 22.13 o posterior.

```bash
npm install
npm run dev
```

La web estará disponible en `http://localhost:3000`.

## Compilación

```bash
npm run build
```

El proyecto es estático: no utiliza autenticación, base de datos, formularios activos ni servicios de seguimiento.
